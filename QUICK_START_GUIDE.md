# Quick Start Guide - Sound Effect Sourcing

## Free Sound Effect Resources (Recommended)

### 1. Freesound.org (Best Overall)
- **URL:** https://freesound.org/
- **Account:** Free registration required
- **License:** Creative Commons (check each file)
- **Quality:** Excellent, user-uploaded
- **Best for:** Almost everything - largest collection

### 2. BBC Sound Effects
- **URL:** https://sound-effects.bbcrewind.co.uk/
- **Account:** Free, no registration
- **License:** Free for non-commercial (theater qualifies)
- **Quality:** Professional BBC archive
- **Best for:** Professional, clean recordings

### 3. Zapsplat
- **URL:** https://www.zapsplat.com/
- **Account:** Free registration
- **License:** Free with attribution
- **Quality:** Very good, curated
- **Best for:** Easy browsing, good search

### 4. YouTube Audio Library
- **URL:** https://studio.youtube.com/channel/UC.../music (requires YouTube account)
- **Account:** Free YouTube account
- **License:** Varies, check each file
- **Quality:** Good
- **Best for:** Music and some sound effects

### 5. Free Music Archive
- **URL:** https://freemusicarchive.org/
- **Account:** Free browsing
- **License:** Creative Commons
- **Quality:** Variable but generally good
- **Best for:** Music (1920s, jazz, Christmas, etc.)

### 6. Archive.org
- **URL:** https://archive.org/
- **Account:** Free browsing
- **License:** Many public domain items
- **Quality:** Variable (historical recordings)
- **Best for:** Vintage/period recordings, authenticity

## File Naming Convention

When you download files, save them as:
```
01_descriptive_name.wav
02_descriptive_name.mp3
03_descriptive_name.ogg
```

Keep numbers sequential in each folder (01, 02, 03, etc.)

## Copyright & Licensing Checklist

Before using ANY sound/music in your production:

- [ ] Is it **public domain**? (Best option)
- [ ] Is it **Creative Commons**? (Check which CC license - some require attribution)
- [ ] Does it allow **theatrical use**? (Some only allow personal use)
- [ ] Do I need to give **attribution**? (Credit in program)
- [ ] Is it **royalty-free** for theater? (Not all "free" music is free for theater)

### Special Attention Needed:
- **Stars and Stripes Forever** - Music is PD, but recording may not be
- **Wedding March** - Music is PD, but recording may not be
- **All Christmas Music** - Verify each recording's license
- **All 1920s/Jazz Music** - Check performance rights

## Recommended Workflow

1. **Start with Freesound.org**
   - Register free account
   - Search for effect
   - Download 2-5 variations
   - Check license (CC0 or CC-BY preferred)

2. **Check BBC Sound Effects**
   - No registration needed
   - Search same term
   - Download alternatives
   - All free for non-commercial use

3. **Use Archive.org for Period Music**
   - Search for public domain recordings
   - Great for authentic 1920s-1940s sounds

4. **Document Your Sources**
   - Keep track of where each file came from
   - Note any attribution requirements
   - Save original filenames in README

## File Format Guide

### Preferred Formats:
1. **WAV** - Best quality, lossless (large files)
2. **OGG** - Good quality, smaller than WAV
3. **MP3** - Most compatible, good enough for theater

### Specifications:
- **Sample Rate:** 44.1kHz or 48kHz
- **Bit Depth:** 16-bit minimum, 24-bit preferred
- **Stereo vs Mono:** Stereo preferred for music, either for SFX

## Period Accuracy Checklist

For 1920s-1940s authenticity:

### ✅ DO USE:
- Rotary phone rings (mechanical bell)
- Steam train whistles
- Vintage car engine sounds (lower RPM)
- Hand-crank police sirens
- Mechanical camera shutters
- 1940s propeller planes
- Period jazz and big band music

### ❌ DON'T USE:
- Digital phone rings
- Diesel train horns
- Modern smooth car engines
- Electronic police sirens
- Digital camera beeps
- Jet engines
- Modern pop music or electronic sounds

## Testing Your Sounds

Before finalizing selections:
1. Test volume levels (normalize if needed)
2. Check for background noise
3. Ensure appropriate duration (trim if too long)
4. Test with your playback system
5. Have backups (that's why 2-5 options per folder!)

## Troubleshooting

**"I can't find the exact sound I need"**
- Try different search terms
- Look for similar sounds you can edit
- Consider layering multiple sounds
- Ask in Freesound.org forums

**"The sound is wrong period"**
- Check Archive.org for historical recordings
- Search for "vintage" or "old" versions
- May need to add processing (make it sound older)

**"The file is too large"**
- Convert WAV to OGG or MP3
- Use Audacity (free) to compress

**"I need to edit the sound"**
- Download Audacity (free, powerful)
- Can trim, fade, normalize, effects
