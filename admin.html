Instructions for Managing Sounds

To add new sounds:

  1. Add MP3 files to the appropriate category folder locally
  2. Run: node cli-tools.js add-sound [category] [filename.mp3]
  3. Commit and push to GitHub: git add . && git commit -m "Add new sound" && git push

To remove sounds:

  1. Run: node cli-tools.js remove-sound [category] [filename.mp3]
  2. Delete the MP3 file from the folder
  3. Commit and push to GitHub
