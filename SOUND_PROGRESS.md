## Technical Notes & Advice

### Finding Sound Effects
- **Free Resources:** Freesound.org, BBC Sound Effects, YouTube Audio Library
- **Paid Options:** Epidemic Sound, AudioJungle, Pond5
- **Format Priority:** WAV (lossless) > OGG (good compression) > MP3 (most compatible)
- **Sample Rate:** Aim for 44.1kHz or 48kHz for professional quality

### Licensing Considerations
- ⚠️ **Music:** Be careful with copyrighted music (Stars & Stripes Forever, Wedding March)
  - Public domain recordings exist for old standards
  - Creative Commons options available
  - Consider commissioning pianist for Christmas music if possible
- ✅ **Sound Effects:** Most SFX libraries offer royalty-free theater licenses

### Organization Tips
- Each folder contains 2-5 numbered options: `01_option1.wav`, `02_option2.wav`, etc.
- Include `README.txt` in folders with notes about each file (duration, quality, source)
- Keep original filenames in README for license tracking

### Context Management
- If context needs compacting, this file serves as checkpoint
- Resume by checking Progress Summary table for "Pending" items
- Each folder name is self-explanatory for quick reference

### Period Authenticity
- **1920s:** Charleston music, rotary phone rings, Model T car sounds
- **1940s:** WWII-era planes, sirens, radio quality recordings
- Anachronistic sounds will break immersion!

### Creative Suggestions
- **Reality Shift:** Consider reversed reverb, pitch-shifted glass harmonica, theremin-like tones
- **Time Slowing:** Stretched audio, deep resonant tones, clock ticking slowed down
- **Angelic Sound:** Choir pad, crystal bowls, shimmering bells, harp glissando
